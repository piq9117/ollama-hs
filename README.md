# ollama-hs

ollama-hs library provides a way to integrate your haskell project with Ollama. 
This library is generated from the [openapi spec](./ollama-openapi.yaml) using [openapi3-code-generator](https://hackage.haskell.org/package/openapi3-code-generator)

## Prerequisites

- [Ollama](https://ollama.com/download) should be installed and running
- Pull a model to use with the library: `ollama pull <model>` e.g. `ollama pull gemma3`
  - See [Ollama.com](https://ollama.com/search) for more information on the models available.

## Cloud Models

See [Ollama Models - Cloud](https://ollama.com/search?c=cloud) for more information

For usage see [ollama-hs-example](./ollama-hs-example)
